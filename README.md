## ⚙️ O'rnatish va Ishga Tushirish

### 1. Repositoryni klonlash:
```bash
git clone https://github.com/Muxiddin-darkcode/rovonuz.git
cd rovonuz
```

### 2. Virtual muhit va kutubxonalar:
```bash
python -m venv venv
.\venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
```

### 3. Konfiguratsiya (.env):
`.env.example` dan nusxa olib, `.env` faylini yarating va kalitlarni to'ldiring:
```bash
cp .env.example .env
```

### 4. Tizimni ishga tushirish:
```bash
python main.py
```
